# 14b - Any 7 Git Commands with GitHub

Scenario: Student Management System.

Commands:
1. git clone
2. git status
3. git branch
4. git switch -c
5. git add
6. git commit
7. git push

Example:
git clone https://github.com/USERNAME/student-management.git
cd student-management
git status
git branch
git switch -c feature/student
git add student.py
git commit -m "Add student feature"
git push -u origin feature/student
