# 15b - GitHub Account / Cloud CI-CD Demonstration

This alternative is documentation-focused because the actual GitHub account must be created by the student.

Suggested demonstration:
1. Create/sign in to GitHub.
2. Create a repository.
3. Push a simple application.
4. Add `.github/workflows/ci.yml`.
5. Push to main.
6. Open Actions and show the workflow run.

Do not put passwords, tokens or private keys in the repository.
Use GitHub Secrets for cloud credentials.
