# 2b - Jira Scrum + DORA Metrics

Create a Jira Scrum project:
Epic -> User Stories -> Sprint.

Map:
- Sprint Planning -> plan work
- Daily Scrum -> continuous coordination
- Sprint Review -> feedback/release validation
- Retrospective -> improvement
- CI/CD -> automated build/test/deploy

Run:
pip install -r requirements.txt
python dora_dashboard.py

The script contains 10 sample points for each of the four DORA metrics.
